# Classifier bootstrap dataset

## Reproducible source

The bootstrap set uses 200 receipt/document images from
[CORD v2](https://huggingface.co/datasets/naver-clova-ix/cord-v2) at the pinned revision
`7f0115a4b758a71d6473b8d085751692da2fef98`. CORD v2 is published under CC BY 4.0.
The downloader records the source URL, normalized-image SHA-256, byte count, dataset revision and
license for every image.

The Hugging Face dataset server currently fails for the CORD `train` split, so the reproducible
default downloads all 100 `validation` and 100 `test` rows as an unlabeled source pool. Those
upstream split names are not used for model evaluation. The builder hashes each source `group_id`
and creates a new 70/15/15 train/validation/test split before generating variants. Consequently,
no synthetic variants of one source image can cross model splits.

```powershell
python -m training.download_classifier_sources `
  --output-root datasets\sources\cord-v2

python -m training.build_classifier_dataset `
  --source-manifest datasets\sources\cord-v2\sources.jsonl `
  --source-root datasets\sources\cord-v2 `
  --output-root datasets\classifier-v2 `
  --seed 2026
```

The generated dataset has 2,600 records from 200 independent source groups: 1,820 train, 390
validation and 390 test. It contains clean samples plus deterministic single and compound variants
for `shadow`, `curved`, `blur`, `moire`, `finger`, `low_contrast` and `color_document`.

## Intended use and limitation

This is a pipeline bootstrap set, not a production quality claim. Its validation and test images
come from held-out documents, but their defects are generated by the same rendering recipes as the
training set. Metrics therefore verify that the model and integration can learn those signals; they
do not measure generalization to arbitrary phone cameras.

Before deployment, add owner-captured, consented phone scans and hard negatives for every label,
especially real fingers, page curvature, screen moire, mixed lighting, glossy paper and meaningful
document colors. Keep scene/burst/document groups intact across splits and retain an untouched
real-photo test set. Record consent, license, capture-device distribution and labeling guidance in
the source manifest.

FUNSD was excluded because its official terms restrict use to non-commercial research. DocBank and
DocLayNet were not mixed into this bootstrap run: their redistribution/size constraints do not
justify silently expanding the local corpus.
